# Walmart Customer Purchase Behavior Analysis

## Project Overview

This project analyzes customer purchase behavior at Walmart Inc. using Exploratory Data Analysis (EDA), the Central Limit Theorem (CLT), and Confidence Interval Analysis.

The goal of this analysis is to understand spending patterns between male and female customers during Black Friday sales and generate business insights for better decision-making.

---

## Objectives

* Analyze customer purchase behavior
* Compare spending patterns by gender
* Apply Central Limit Theorem (CLT)
* Generate sampling distributions
* Calculate 95% Confidence Intervals
* Provide business recommendations

## Statistical Concepts Used

### Central Limit Theorem (CLT)

\bar{X} \approx N\left(\mu, \frac{\sigma}{\sqrt{n}}\right)

### Confidence Interval Formula

CI = \bar{x} \pm z \left(\frac{\sigma}{\sqrt{n}}\right)
